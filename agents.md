# Agent instructions

Run `cargo bake agent:context:install` to install dependency context and skills. Use `cargo bake agent:context:list` and `cargo bake agent:context:show` to discover guidance. Read `.agents/conventions.md` and the skills relevant to the task. Keep repository instructions here; the installer preserves this file.

Read `context/task-libraries.md` and `context/testing-task-libraries.md` before changing task registration, library interfaces, or task tests.
